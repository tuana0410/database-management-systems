# YZM307 - Database Management Systems 🗄️

This repository contains coursework, SQL scripts, relational database design projects, and practice files for the **YZM307 Database and Management Systems** course.

##  Contents
- **SQL Scripts:** Data Definition Language (DDL), Data Manipulation Language (DML), Joins, Subqueries, and Stored Procedures.
- **Database Design:** ER diagrams, relational mappings, and normalization exercises.
- **Implementations:** Mini relational database project files.

##  Technologies & Tools
- PostgreSQL / MSSQL
- SQL
- Entity Framework Core / LINQ
